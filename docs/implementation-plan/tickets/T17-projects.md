# T17 — Зеркальный пояс и Конденсатор тумана

Статус: запланирован. Веха: M2.

## Основная идея

Большие стройки связывают районы и меняют масштаб карты.

## Цель

Два промежуточных проекта дают реальный эффект, подготавливая финал.

## Входные условия

Завершены: [T16](T16-resonance.md).

Прочитать [IDEA](../IDEA.md), [SCOPE](../SCOPE.md), [архитектуру](../ARCHITECTURE.md), [состояние](../STATE-AND-SAVE.md), [экономику](../ECONOMY.md) и [проверки](../VERIFICATION.md). При противоречии сначала актуализировать общий договор в [DECISIONS](../DECISIONS.md).

## Входит в тикет

- Многошаговые рецепты, строительство и эффекты Зеркального пояса/Конденсатора.
- Оптические потери/дальность и резонансные усилители выбранных производств.

## За границами тикета

Финальное Сердце света, универсальная редакторская система произвольных мегаструктур.

## Необходимые детали реализации

- Рецепты используют уже существующие ресурсы; каждый этап имеет явное списание и условия.
- Базовый колодец производит резонанс до Конденсатора, исключить циклическую зависимость запуска.
- Новые трассы и усилители согласуются с приоритетами мощности. Добавить стадии, эффекты и пороги эхо в каталог/сохранение.

## Критерии приёмки

- [ ] Оба проекта достижимы без конкретного постоянного перка.
- [ ] Каждый меняет наблюдаемую работу экономики и вид карты.
- [ ] Повторная команда завершённого этапа не списывает цену; загрузка не применяет бонус повторно.

## Проверка

Поэтапные цены, частичная стройка, применение эффекта один раз и граф достижимости рецептов; ручное сравнение карты/производства.

Игровые тесты писать только через согласованные интерфейсы. В записи результата указать выполненные проверки, наблюдаемый итог и оставшиеся ограничения.

## Финальный результат

Две большие стройки с пользой для существующих районов.

Коммит содержит ID T17, изменения и короткую запись проверки. Следующий тикет начинает работу с этого наблюдаемого результата.
