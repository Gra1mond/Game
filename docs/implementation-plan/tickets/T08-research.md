# T08 — Исследования и первые взаимные усиления

Статус: запланирован. Веха: M1.

## Основная идея

Новый район повышает ценность ранних производств.

## Цель

Данные дают исследования, а кварцевая оптика заметно улучшает уже работающий порт или генерацию.

## Входные условия

Завершены: [T07](T07-quartz.md).

Прочитать [IDEA](../IDEA.md), [SCOPE](../SCOPE.md), [архитектуру](../ARCHITECTURE.md), [состояние](../STATE-AND-SAVE.md), [экономику](../ECONOMY.md) и [проверки](../VERIFICATION.md). При противоречии сначала актуализировать общий договор в [DECISIONS](../DECISIONS.md).

## Входит в тикет

- Исследовательское назначение на корабле, данные и меню обычных улучшений.
- Вместимость, устойчивость насоса, оптика и базовая автоматизация с ограниченными уровнями.

## За границами тикета

Массовое производство данных города и постоянное метадерево.

## Необходимые детали реализации

- Корабельное исследование доступно до города и занимает настоящего рабочего.
- Цены/уровни/эффекты находятся в каталоге; UI получает предпросмотр из правил.
- Применять группы бонусов в порядке ARCHITECTURE/ECONOMY; оптика должна менять наблюдаемое ограничение, а не только подпись дохода.

## Критерии приёмки

- [ ] Можно получить данные и исследовать улучшение без пятого района.
- [ ] Оптика за кварц ускоряет раннее производство; изменение видно на цикле и показателях.
- [ ] Покупка максимального уровня отклоняется без расхода; автоматизация работает в первом цикле.

## Проверка

Ручной пример стоимости и эффекта, отказ при нехватке, сочетание луча/исследования; прохождение связи рифы → порт.

Игровые тесты писать только через согласованные интерфейсы. В записи результата указать выполненные проверки, наблюдаемый итог и оставшиеся ограничения.

## Финальный результат

Первый замкнутый контур развития между районами.

Коммит содержит ID T08, изменения и короткую запись проверки. Следующий тикет начинает работу с этого наблюдаемого результата.
