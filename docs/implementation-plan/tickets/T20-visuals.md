# T20 — Карта, машины и видимый рост

Статус: запланирован. Веха: M2.

## Основная идея

Работа системы читается при приближении и радует при отдалении.

## Цель

Районы различимы, движение объясняет добычу, сооружения показывают масштаб развития.

## Входные условия

Завершены: [T19](T19-finale.md).

Прочитать [IDEA](../IDEA.md), [SCOPE](../SCOPE.md), [архитектуру](../ARCHITECTURE.md), [состояние](../STATE-AND-SAVE.md), [экономику](../ECONOMY.md) и [проверки](../VERIFICATION.md). При противоречии сначала актуализировать общий договор в [DECISIONS](../DECISIONS.md).

## Входит в тикет

- Согласованная 2D-графика шести районов, света/тумана и проектов.
- Представление маршрутов/фаз, уровни детализации карты и композиция панелей.

## За границами тикета

Изменение правил экономики, сложная физика жидкости, кинематографические ролики.

## Необходимые детали реализации

- Анимации читают снимок, не выдают награды. Удалённая визуализация не выключает симуляцию.
- Объекты стадий/уровней используют существующие состояния; снижение детализации не прячет важную информацию.
- Шрифты и ассеты имеют фиксированное происхождение/лицензию, текст вынесен в каталог строк.

## Критерии приёмки

- [ ] Шесть процессов различимы визуально, направление луча и состояние сети читаются.
- [ ] При смене масштаба и экрана прогресс продолжается корректно.
- [ ] Сравнение начала/середины/финала показывает рост; UI работает на выбранном минимальном разрешении.

## Проверка

Снимки трёх стадий и нескольких масштабов; контроль соответствия движения данным; замер тяжёлой сцены для T23.

Игровые тесты писать только через согласованные интерфейсы. В записи результата указать выполненные проверки, наблюдаемый итог и оставшиеся ограничения.

## Финальный результат

Цельное визуальное представление уже реализованной кампании.

Коммит содержит ID T20, изменения и короткую запись проверки. Следующий тикет начинает работу с этого наблюдаемого результата.
