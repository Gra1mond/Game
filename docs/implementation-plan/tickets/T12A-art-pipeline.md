# T12A — Локальный арт-конвейер и настоящая 3D-карточка

Статус: запланирован. Веха: M1. Добавлен без перенумерации существующих тикетов.

## Основная идея

Сначала доказать маленький законченный набор реалистичной морской техники в настоящей игре, затем размножать ассеты.

## Цель

Воспроизводимо получить Плавучий маяк/корабль, сборщик и порт; показать их в фиксированном наклонном 2D-мире и native 3D-карточке, включая реальное улучшение сборщика. Этот gate обязателен до массового производства арта и до T13; это не заявление о готовых сейчас моделях.

## Входные условия

Завершён [T12](T12-opening.md). Уже существуют игровые улучшения, сохранения и рабочий M1 без персонажей. Пилот выполняется до приёмки T13 и массового художественного набора.

Прочитать [IDEA](../IDEA.md), [SCOPE](../SCOPE.md), [архитектуру](../ARCHITECTURE.md), [состояние](../STATE-AND-SAVE.md), [экономику](../ECONOMY.md), [проверки](../VERIFICATION.md), [ART-AND-ASSETS](../ART-AND-ASSETS.md) и [SKILLS-RESEARCH](../SKILLS-RESEARCH.md). При противоречии сначала актуализировать общий договор в [DECISIONS](../DECISIONS.md). Конвейер авторства требует отдельно разрешённой подготовки локального Blender/зависимостей; устанавливать инструменты только после такого разрешения.

## Входит в тикет

- Небольшой законченный набор корабль + сборщик + порт; минимум две содержательно разные версии сборщика base/upgraded, а не перекраска примитива.
- Редактируемый source, проектные Blender Python-параметры/seed, точный version lock, local bake/export recipe, manifest с происхождением/лицензиями и runtime outputs GLB/PBR images + PNG мира.
- Фиксированный наклонный ракурс мира; native минимальная карточка с большим настоящим 3D-объектом, реальной статистикой, основным действием и одним изолированным preview.
- Спокойное общее вращение, короткое ускорение и смена actual upgraded model после успешного содержательного улучшения; pause/reduced motion с первого внедрения.
- Проверяемое качество, реальный Godot import/render, измерения открытого/закрытого preview, доказательство upgrade и честный отчёт о Windows-возможностях/ограничениях среды.

## За границами тикета

Массовые ассеты всех районов, человеческие модели, экипаж/герои/найм/личный XP (только M2/T17A–T17B), свободная 3D-камера мира, новые экономические правила, платная/облачная генерация, сложный topology morph, runtime Blender/MCP. Не заменять неудавшийся арт примитивом под видом выполненной генерации.

## Необходимые детали реализации

- Source/tools/manifest и game runtime outputs разделены по ART-AND-ASSETS. Не добавлять `.blend` как обязательный runtime/import путь. Версии Blender/exporter/плагинов закреплять по реально подготовленной среде, не выдумывать их сейчас; Godot остаётся 4.7.2 Compatibility.
- Один recipe воспроизводит все три объекта и обе collector-версии из сохранённых источников/параметров. Bake/simplify procedural weathering в поддерживаемые image PBR. Экспортировать явную коллекцию версии; не захватывать весь source world. Ошибка bake/export/validation означает ошибку команды, не успешное копирование входа.
- Сборщик должен выглядеть как изготовленная морская машина с правдоподобными корпусом/узлами, пропорциями, износом краски, коррозией и ремонтом; осмотреть полный оборот. Upgraded меняет видимый корпус/рабочий модуль по реальному улучшению, сохраняя согласованные units, pivot, направление, scale и framing. PNG base/upgraded имеют одинаковую систему camera/light/anchor.
- Карточка — Control + SubViewport/World3D/Camera3D. Во всём интерфейсе один активный видимый preview. Списки/скрытые карточки не держат собственные рендеры; hidden viewport и его animation processing остановлены. Статичная reduced-motion карточка может отрисоваться один раз.
- Preview демонстрирует версию, не фактический цикл. Статистика, назначение, питание, состояние и цена читаются из snapshot; карта продолжает отражать реальные фазы. Нет наград/XP за вращение, открытие, закрытие или обновление UI.
- Одинаковая спокойная базовая скорость для всех моделей; успешный geometry-tier upgrade временно плавно ускоряет spin, меняет модель/fade без скачка кадра и возвращает baseline. +1% без новой visual-version меняет данные, не требует mesh. Неуспешная покупка/load/reopen не воспроизводят успешную покупку. При pause/reduced motion — статичная смена без ускорения.
- Состав карточки минимален: название/версия, большая модель, несколько важных фактов, primary action с ценой/причиной недоступности. Информация не только цветом; доступные подписи, фокус и rotation pause. В M1 не дорисовывать фиктивных людей.
- Manifest фиксирует binding/version, source/recipe/seed/lock, outputs/hashes, axes/units/pivot/bounds, camera/light/PNG anchor, triangle/material/texture/import budget, source URL/author/license/notice каждого компонента и доказательства приёмки.
- Измерить baseline, preview, upgrade и hidden-состояние, записать hardware/OS/renderer/resolution, frame time/p95, draw calls, память и import time; по результатам закрепить числовые лимиты до bulk assets. Отдельно указать Windows native/exported результат либо точную недоступную среду; Linux/WSL-кадр не считать Windows-proof. Непроверенный Windows-пункт остаётся обязательным для последующих gates, не считается пройденным.

## Критерии приёмки

- [ ] Все три объекта представлены законченными моделями и PNG в мире; полный оборот показывает материал/силуэт без blockout-примитивов, пропавших сторон и текстур.
- [ ] Существуют base/upgraded сборщик с заметным реальным изменением конструкции, совпадающими опорами/масштабом и стабильным framing; карточка показывает текущую приобретённую версию.
- [ ] Чистый повторный bake/export из сохранённого source/seed/lock воспроизводит структуру/материалы/кадрирование; игровой импорт GLB/PNG не требует установленного Blender и не теряет baked PBR.
- [ ] Manifest и лицензии заполнены для каждого компонента; реальные GLB/texture/output validation ловят missing texture/output/license, пустую/неверную геометрию и неверную версию, а не только ищут source strings.
- [ ] В Godot 4.7.2 Compatibility видны реальные карта/3D-preview и успешный upgrade; ускорение временное, baseline единый, +1% без tier не требует новой сетки.
- [ ] Pause/reduced motion/клавиатура и текстовые состояния работают; reopen/load/failed purchase не имитируют покупку. Анимация не влияет на production/XP, даже когда карточка скрыта.
- [ ] Наблюдением/профилированием подтверждены один preview и отсутствие скрытого rendering/animation work; симуляция без карточки продолжается.
- [ ] Сохранены render captures/upgrade video или эквивалентная наблюдаемая запись, измеренный бюджет и платформенный отчёт с точными выполненными/непроверенными пунктами. Одних headless/source checks или чужого upstream report недостаточно для разрешения массового арта.

## Проверка

Затронутые игровые правила проверять через публичные интерфейсы по `/tdd`; постоянный новый тест нужен только для нового риска/границы поведения, не для путей GLB, копирования binding или структуры сцены. UI/вращение проверять настоящим запуском. Выполнить чистый bake/export и artifact validation с отсутствующей текстурой/неверной версией; реальный Godot import/render полного оборота и карты. Маршрут: открыть → успешное/отклонённое улучшение → числовое улучшение без нового mesh tier → сменить объект в переходе → закрыть → pause/reduced motion → сохранить/загрузить. Сопоставить snapshot и карточку; снять метрики baseline/open/upgrade/hidden, указать доступность Windows и честные пределы доказательства.

Игровые тесты писать только через согласованные интерфейсы. В записи результата указать выполненные проверки, наблюдаемый итог и оставшиеся ограничения. Исследование/изменение спецификации само эти проверки не выполняет.

## Финальный результат

Маленький воспроизводимый и визуально принятый asset pipeline с настоящей native 3D-карточкой и явными ограничениями для расширения T20. Технически успешный GLB без утверждённого качества не закрывает тикет и не открывает bulk-генерацию. Человеческий процесс начинается в M2 при T17A, не переносится в этот gate.

Коммит содержит ID T12A, изменения и короткую запись проверки. По исходному порядку: TDD → запуск/приёмка → commit/push/отдельный PR в dev → STOP и подтверждение пользователя; следующий тикет не начинать автоматически.
