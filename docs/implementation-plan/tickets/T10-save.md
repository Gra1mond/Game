# T10 — Сохранение и восстановление текущей экспедиции

Статус: запланирован. Веха: M1.

## Основная идея

Игрок продолжает ровно то прохождение, которое закрыл.

## Цель

Сохраняются кошелёк, фазы, груз, назначения, луч, исследования и построенный маяк.

## Входные условия

Завершены: [T09](T09-goals.md).

Прочитать [IDEA](../IDEA.md), [SCOPE](../SCOPE.md), [архитектуру](../ARCHITECTURE.md), [состояние](../STATE-AND-SAVE.md), [экономику](../ECONOMY.md) и [проверки](../VERIFICATION.md). При противоречии сначала актуализировать общий договор в [DECISIONS](../DECISIONS.md).

## Входит в тикет

- SaveRepository v1, полный профиль, autosave, загрузка/продолжение и backup.
- Валидация, версии, последовательность записей и сообщения о восстановлении.

## За границами тикета

Офлайн-доход, облако, синхронизация между устройствами и престиж.

## Необходимые детали реализации

- Следовать STATE-AND-SAVE; настройки отдельно. Одна последовательная очередь записей, revision монотонна.
- Проверить продвижение временного файла и резервной копии на Windows, ошибки места/доступа обрабатывать без нового пустого профиля.
- Загрузка пересчитывает производные показатели, сохраняет незавершённые действия; несовместимую будущую версию не перезаписывать.

## Критерии приёмки

- [ ] Выход во время доставки/бурения возвращает один и тот же незавершённый цикл без бесплатной выплаты.
- [ ] Повреждённый основной файл восстанавливается из допустимого снимка с сообщением.
- [ ] Ошибка записи оставляет прежнее сохранение; закрытая игра не производит ресурсы.

## Проверка

Согласованный SaveRepository seam: round trip полного состояния, повреждение, незавершённый tmp, порядок revision, будущая версия; вручную перезапуск приложения.

Игровые тесты писать только через согласованные интерфейсы. В записи результата указать выполненные проверки, наблюдаемый итог и оставшиеся ограничения.

## Финальный результат

Надёжное продолжение M1 до добавления операции сброса.

Коммит содержит ID T10, изменения и короткую запись проверки. Следующий тикет начинает работу с этого наблюдаемого результата.
