# T11 — Первый полный цикл престижа

Статус: запланирован. Веха: M1.

## Основная идея

Завершённая экспедиция даёт новые возможности следующей.

## Цель

Игрок видит награду, выбирает постоянные улучшения, сбрасывается и продолжает с сохранённым эхо.

## Входные условия

Завершены: [T10](T10-save.md).

Прочитать [IDEA](../IDEA.md), [SCOPE](../SCOPE.md), [архитектуру](../ARCHITECTURE.md), [состояние](../STATE-AND-SAVE.md), [экономику](../ECONOMY.md) и [проверки](../VERIFICATION.md). При противоречии сначала актуализировать общий договор в [DECISIONS](../DECISIONS.md).

## Входит в тикет

- Реестр milestone IDs, предпросмотр, подтверждение, небольшой набор навыков трёх направлений.
- Атомарный кандидат профиля, новый цикл, перераспределение и сохранение до/после престижа.

## За границами тикета

Полное метадерево M2, покупка удобства базового UI за эхо, принудительный сброс по времени.

## Необходимые детали реализации

- Начальные 5 очков и новые пороги второго цикла заданы в ECONOMY; добавить их до завершения задачи.
- Сумма allocation не больше total_echo. Бесплатное перераспределение при подготовке; эффекты стартовых навыков применяются один раз.
- Престиж доступен после маяка и новой награды; отмена ничего не меняет. При ошибке записи активный профиль остаётся прежним.

## Критерии приёмки

- [ ] Предпросмотр точно соответствует полученному эхо, потерям и сохранённым полям.
- [ ] Повторный клик/загрузка не дублирует награду; сбой даёт целый старый или новый профиль.
- [ ] Два разных набора очков работоспособны; во втором цикле есть достижимый новый рубеж M1.

## Проверка

preview без мутации, cancel, нехватка очков, повторная фиксация, ошибка записи и загрузка после commit; ручное повторное прохождение.

Игровые тесты писать только через согласованные интерфейсы. В записи результата указать выполненные проверки, наблюдаемый итог и оставшиеся ограничения.

## Финальный результат

Полный престиж с сохранением и содержательным вторым стартом.

Коммит содержит ID T11, изменения и короткую запись проверки. Следующий тикет начинает работу с этого наблюдаемого результата.
