# T23 — Надёжность и производительность полной версии

Статус: запланирован. Веха: M2.

## Основная идея

Длинное прохождение остаётся целым и отзывчивым.

## Цель

Поздний профиль быстро работает и восстанавливается после реалистичных сбоев.

## Входные условия

Завершены: [T22](T22-balance.md).

Прочитать [IDEA](../IDEA.md), [SCOPE](../SCOPE.md), [архитектуру](../ARCHITECTURE.md), [состояние](../STATE-AND-SAVE.md), [экономику](../ECONOMY.md) и [проверки](../VERIFICATION.md). При противоречии сначала актуализировать общий договор в [DECISIONS](../DECISIONS.md).

## Входит в тикет

- Интеграция сохранений всех районов/проектов, миграции M1 и ошибки записи.
- Профилирование эталонного позднего состояния, оптимизация конкретных узких мест.

## За границами тикета

Переписывание архитектуры без измерений, сетевое облако, расширение игровых механик.

## Необходимые детали реализации

- Бюджет производительности фиксируется с конкретным оборудованием/разрешением и нагрузкой.
- Симуляция скрытых районов сохраняется при оптимизации графики; поздние числа остаются конечными.
- Проверить весь профиль, настройки и престиж при прерывании записи; не считать успешный happy path достаточным.

## Критерии приёмки

- [ ] M1/M2-профили загружаются, незавершённые процессы не дублируются.
- [ ] Повреждение/сбой записи имеют описанное восстановление, будущий формат не затирается.
- [ ] Эталонная поздняя сцена соответствует зафиксированному бюджету, измерения приложены.

## Проверка

Матрица SaveRepository и prestige из VERIFICATION, длительный прогон, профилирование; регрессия правил после оптимизации.

Игровые тесты писать только через согласованные интерфейсы. В записи результата указать выполненные проверки, наблюдаемый итог и оставшиеся ограничения.

## Финальный результат

Отчёт надёжности/производительности и исправленные конкретные проблемы.

Коммит содержит ID T23, изменения и короткую запись проверки. Следующий тикет начинает работу с этого наблюдаемого результата.
