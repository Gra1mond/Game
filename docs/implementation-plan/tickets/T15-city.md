# T15 — Затопленный город и поток данных

Статус: запланирован. Веха: M2.

## Основная идея

Исследования ускоряются через двухстадийное производство.

## Цель

Игрок распределяет мощность между поиском сигналов и их расшифровкой.

## Входные условия

Завершены: [T14](T14-biomass.md).

Прочитать [IDEA](../IDEA.md), [SCOPE](../SCOPE.md), [архитектуру](../ARCHITECTURE.md), [состояние](../STATE-AND-SAVE.md), [экономику](../ECONOMY.md) и [проверки](../VERIFICATION.md). При противоречии сначала актуализировать общий договор в [DECISIONS](../DECISIONS.md).

## Входит в тикет

- Сонар, ограниченная очередь, декодеры, данные города и эффекты луча.
- Гарантированные сюжетные чертежи, новые обычные исследования, сохранение очереди.

## За границами тикета

Пазл для каждого сигнала, рынок/торговля и замена всей экономики одним новым ресурсом.

## Необходимые детали реализации

- При заполнении очереди поиск останавливается с причиной; незаполненный декодер не выдаёт данные.
- Обязательный чертёж получается по известному порогу расшифровки, не случайной редкости.
- Корабельный источник данных остаётся валиден; новые исследования улучшают ранние районы и имеют понятные цены.

## Критерии приёмки

- [ ] Изменение распределения влияет на очередь и выпуск, а не только на две одинаковые скорости.
- [ ] Город значительно усиливает исследования, обязательные чертежи гарантированы.
- [ ] Профиль до города загружается, содержимое очереди и частично расшифрованный сигнал восстанавливаются.

## Проверка

Пустая/полная очередь, переключение питания на границе, загрузка и однократность чертежа; ручная связь город → ранняя фабрика.

Игровые тесты писать только через согласованные интерфейсы. В записи результата указать выполненные проверки, наблюдаемый итог и оставшиеся ограничения.

## Финальный результат

Пятый район, новый способ управления и сюжетное продвижение.

Коммит содержит ID T15, изменения и короткую запись проверки. Следующий тикет начинает работу с этого наблюдаемого результата.
