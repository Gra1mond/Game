# T19 — Сердце света и завершение истории

Статус: запланирован. Веха: M2.

## Основная идея

Конечная цель использует построенную систему и показывает результат освоения мира.

## Цель

Игрок собирает многостадийное Сердце света и получает полноценный финал.

## Входные условия

Завершены: [T18](T18-meta.md).

Прочитать [IDEA](../IDEA.md), [SCOPE](../SCOPE.md), [архитектуру](../ARCHITECTURE.md), [состояние](../STATE-AND-SAVE.md), [экономику](../ECONOMY.md) и [проверки](../VERIFICATION.md). При противоречии сначала актуализировать общий договор в [DECISIONS](../DECISIONS.md).

## Входит в тикет

- Рецепты и условия финальных этапов с вкладом всех шести районов.
- Последняя часть сигнала, изменение карты, финальная последовательность и итоговый экран.

## За границами тикета

Вторая кампания, бесконечный эндгейм, новые ресурсы после финала.

## Необходимые детали реализации

- Использовать несколько этапов, а не одно гигантское ожидание одного ресурса. Показать требования устойчивого выпуска и фактические ограничения.
- Финал одноразов по run_id, флаг завершения сохраняется до возвращения в меню.
- После титров доступно меню и загрузка завершённого профиля с просмотром мира; новый цикл начинается только по явному действию.

## Критерии приёмки

- [ ] Финал достижим действующими системами и использует все районы.
- [ ] История сигнала получает ответ; изменение мира видно и сопровождается итогом.
- [ ] Выход/загрузка во время или после последовательности не теряет завершение и не списывает ресурсы снова.

## Проверка

Предфинальный профиль, все этапы, отказ при недостающем условии, повторная загрузка финала; ручная оценка понятности и завершённости.

Игровые тесты писать только через согласованные интерфейсы. В записи результата указать выполненные проверки, наблюдаемый итог и оставшиеся ограничения.

## Финальный результат

Полная кампания с осмысленным окончанием.

Коммит содержит ID T19, изменения и короткую запись проверки. Следующий тикет начинает работу с этого наблюдаемого результата.
