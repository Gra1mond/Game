# T07 — Кварцевые рифы

Статус: реализован и проверен; [PR #6 в dev](https://github.com/Gra1mond/Game/pull/6) открыт, `feat/T07-quartz`, основной коммит `87aa0f8`. Ожидает подтверждения пользователя перед T08; автоматически не сливать. Веха: M1.

## Основная идея

Третий ресурс добывается фазовым процессом, чувствительным к распределению энергии.

## Цель

Бур заряжается, раскалывает жилу и охлаждается; игрок выбирает, сколько буров питать.

## Входные условия

Завершены: [T06](T06-oil.md).

Прочитать [IDEA](../IDEA.md), [SCOPE](../SCOPE.md), [архитектуру](../ARCHITECTURE.md), [состояние](../STATE-AND-SAVE.md), [экономику](../ECONOMY.md) и [проверки](../VERIFICATION.md). При противоречии сначала актуализировать общий договор в [DECISIONS](../DECISIONS.md).

## Входит в тикет

- Открытие рифов, станция, назначение работников и три фазы бурения.
- Кварц в кошельке, параметры мощности, эффект главного луча и панель цикла.
- Первый потребитель кварца: покупаемая кварцевая линза самого бура, сокращающая его заряд. Межрайонная оптика остаётся T08.
- Рифы добавляются как цель масляного форсажа из T06: масло ускоряет заряд по общему правилу временных эффектов.

## За границами тикета

Светомасса, произвольные формы лучей, финальные улучшения оптики.

## Необходимые детали реализации

- Условия открытия задаются выпуском текущего цикла после освоения двух стартовых районов.
- Цена запуска доступна экономике T06; фазовый прогресс переживает временное отсутствие питания.
- Кварц выдаётся один раз за завершённый скол. Повышенная мощность ускоряет заряд, не отменяет охлаждение.
- Локальная линза необязательна для первого запуска: цену можно накопить базовым буром. Значение улучшения и предпросмотр берутся из каталога.

## Критерии приёмки

- [x] Разделение энергии между бурами даёт наблюдаемое изменение циклов.
- [x] Отключение/возврат питания не дублирует кварц.
- [x] Игрок получает третий материал без обязательной случайной находки; причина простоя видна.
- [x] Добытый кварц можно потратить в этом тикете, увидев сокращение следующего заряда без отмены охлаждения.

## Проверка

Полный цикл, остановка на каждой фазе, переключение луча, два бура с ограниченной мощностью.

Игровые тесты писать только через согласованные интерфейсы. В записи результата указать выполненные проверки, наблюдаемый итог и оставшиеся ограничения.

## Финальный результат

Три действительно разных производства в одной работающей экономике.

Коммит содержит ID T07, изменения и короткую запись проверки. Следующий тикет начинает работу с этого наблюдаемого результата.

## Сверка реализации — 2026-11-03

- Семь последовательных RED→GREEN через GameSession: выплата только после скола/полный цикл; порог двух стартовых производств; луч посреди заряда; два бура с разной мощностью и аддитивным маслом; смена оплачиваемой цели; линза во время охлаждения; неизменность уже начатого заряда. Полный Linux `scripts/check.py`: все `.gd` компилируются,37/37; отдельный Windows headless37/37.
- Критерий1: в настоящем Windows-рендере построены два бура, назначены отдельные W3/W1. При включённом порте второй ждал питания; выключена только портовая станция, не её транзитное реле. Запросы1.5 и1 вместе с насосом/реле заняли ровно4. Первый бур с линзой получил заряд4с вместо6; измеренная работа за секунду соответствовала мощности1.5. Второй показывал8с при мощности1.
- Критерий2: отдельный CLI-smoke остановил charge/fracture/cooling на2/8.5/10.5с, сохранил состояние станции/кварц за3с отключения и после включения получил ровно следующую партию4. Очередь нагруженного сборщика сохранила груз, исключила второго оператора и не засчитала такт доставки как работу бура. В Windows UI выключение также остановило фазу/выдачу и обработку схемы; восстановление дало настоящую партию.
- Критерий3: нативный сценарий прошёл от40 сплава через ручной сбор, порт и насос до третьего материала без команд выдачи/ускорения времени. Условия открытия, отсутствие рабочего и дефицит питания подписаны; кварц выдавался за скол. Итог: выпуск сплава113/масла40/кварца20, запас10/16.85/16 соответственно, два бура, бюджет4из4.
- Критерий4: первая базовая партия4 оплачивает локальную линзу. В Windows куплена при охлаждении: установленная линза1, цикл ещё с линзой0 и неизменным охлаждением, следующий заряд6с вместо8. Тест покупки посреди заряда дополнительно доказал отсутствие ретроактивного ускорения: выплата на22с, следующий улучшенный цикл на33с.
- Луч/масло: выбран quartz, расход0.5 масла/с отдельно от генератора; с лучом временная скорость×2.5. Следующие заряды составили1.6с и3.2с для двух разных буров; получены настоящие новые партии. Выключение форсажа сняло бонус, пауза сохранила целый профиль и остановила обработку схемы.
