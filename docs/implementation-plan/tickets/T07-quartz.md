# T07 — Кварцевые рифы

Статус: запланирован. Веха: M1.

## Основная идея

Третий ресурс добывается фазовым процессом, чувствительным к распределению энергии.

## Цель

Бур заряжается, раскалывает жилу и охлаждается; игрок выбирает, сколько буров питать.

## Входные условия

Завершены: [T06](T06-oil.md).

Прочитать [IDEA](../IDEA.md), [SCOPE](../SCOPE.md), [архитектуру](../ARCHITECTURE.md), [состояние](../STATE-AND-SAVE.md), [экономику](../ECONOMY.md) и [проверки](../VERIFICATION.md). При противоречии сначала актуализировать общий договор в [DECISIONS](../DECISIONS.md).

## Входит в тикет

- Открытие рифов, станция, назначение работников и три фазы бурения.
- Кварц в кошельке, параметры мощности, эффект главного луча и панель цикла.

## За границами тикета

Светомасса, произвольные формы лучей, финальные улучшения оптики.

## Необходимые детали реализации

- Условия открытия задаются выпуском текущего цикла после освоения двух стартовых районов.
- Цена запуска доступна экономике T06; фазовый прогресс переживает временное отсутствие питания.
- Кварц выдаётся один раз за завершённый скол. Повышенная мощность ускоряет заряд, не отменяет охлаждение.

## Критерии приёмки

- [ ] Разделение энергии между бурами даёт наблюдаемое изменение циклов.
- [ ] Отключение/возврат питания не дублирует кварц.
- [ ] Игрок получает третий материал без обязательной случайной находки; причина простоя видна.

## Проверка

Полный цикл, остановка на каждой фазе, переключение луча, два бура с ограниченной мощностью.

Игровые тесты писать только через согласованные интерфейсы. В записи результата указать выполненные проверки, наблюдаемый итог и оставшиеся ограничения.

## Финальный результат

Три действительно разных производства в одной работающей экономике.

Коммит содержит ID T07, изменения и короткую запись проверки. Следующий тикет начинает работу с этого наблюдаемого результата.
