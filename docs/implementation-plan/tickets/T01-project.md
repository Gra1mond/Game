# T01 — Запускаемый проект и команды проверки

Статус: запланирован. Веха: M1.

## Основная идея

Получить минимальную основу, которую можно одинаково запустить и проверить на Windows.

## Цель

Пустая сцена карты открывается, пауза работает, версия движка и команды воспроизводимы.

## Входные условия

Завершены: нет зависимостей; исходные материалы сохранены в Git.

Прочитать [IDEA](../IDEA.md), [SCOPE](../SCOPE.md), [архитектуру](../ARCHITECTURE.md), [состояние](../STATE-AND-SAVE.md), [экономику](../ECONOMY.md) и [проверки](../VERIFICATION.md). При противоречии сначала актуализировать общий договор в [DECISIONS](../DECISIONS.md).

## Входит в тикет

- Создать game/project.godot, стартовую сцену, типизированный GDScript и Compatibility renderer.
- Добавить локальную инструкцию установки официального движка, .gitignore и раннер проверок.

## За границами тикета

Добыча, игровые цены, ассеты финального качества и установка движка без необходимости в этой задаче.

## Необходимые детали реализации

- Проверить текущую стабильную Godot 4; записать точную версию, путь/алиас и экспортные шаблоны.
- До первого игрового теста согласовать предложенные seams из VERIFICATION. Раннер принимает --case, возвращает ненулевой код при ошибке и не пишет в обычный профиль.
- Проверка парсера охватывает все скрипты, включая неиспользованные сценой; пустой набор не выдаётся за проверенную игру.

## Критерии приёмки

- [ ] Проект запускается из чистого checkout по инструкции.
- [ ] Пауза переключается, русские строки отображаются; импорты и раннер завершаются предсказуемо.
- [ ] Есть эталон оборудования/разрешения и начальный замер для будущего бюджета производительности.

## Проверка

Запуск редактора/проекта, штатный выход; намеренно ошибочный временный скрипт подтверждает ошибочный exit code, после проверки удаляется.

Игровые тесты писать только через согласованные интерфейсы. В записи результата указать выполненные проверки, наблюдаемый итог и оставшиеся ограничения.

## Финальный результат

Основа проекта и README с точными командами, версией и результатами проверки.

Коммит содержит ID T01, изменения и короткую запись проверки. Следующий тикет начинает работу с этого наблюдаемого результата.
