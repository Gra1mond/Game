# T03 — Сборщики и Кладбище кораблей

Статус: запланирован. Веха: M1.

## Основная идея

Добыча сплава становится наблюдаемым циклом перевозки груза.

## Цель

Построенный сборщик отправляется к обломку, загружается, возвращается и выдаёт сплав.

## Входные условия

Завершены: [T02](T02-simulation.md).

Прочитать [IDEA](../IDEA.md), [SCOPE](../SCOPE.md), [архитектуру](../ARCHITECTURE.md), [состояние](../STATE-AND-SAVE.md), [экономику](../ECONOMY.md) и [проверки](../VERIFICATION.md). При противоречии сначала актуализировать общий договор в [DECISIONS](../DECISIONS.md).

## Входит в тикет

- Покупка работников, назначение/возврат и две цели с разными расстояниями/грузом.
- Простая визуализация маршрута, переносимого груза, фазы и параметров вместимости/скорости.

## За границами тикета

Свободная навигация, столкновения судов, сложная общая логистика между всеми районами.

## Необходимые детали реализации

- Назначение одно на worker ID. Возврат во время перевозки завершает возврат с уже полученным грузом; новая задача начинается затем.
- Зафиксировать rule возврата до погрузки и начала новой цели. Награда выплачивается при доставке, не по визуальному событию.
- Как минимум одна ближняя цель возобновляется и не оставляет игрока без дохода. Начальный пример цикла дан в ECONOMY.

## Критерии приёмки

- [ ] Две цели имеют объяснимую разницу в отдаче; улучшенная вместимость влияет на выбор.
- [ ] Покупка списывает цену один раз; недостаток сплава объяснён.
- [ ] Переназначение не создаёт копию рабочего или груза; порт восстанавливается после неудачной покупки.

## Проверка

Доставка за известный цикл, возврат на разных фазах, отсутствие двойной выплаты; ручное наблюдение пути и панели.

Игровые тесты писать только через согласованные интерфейсы. В записи результата указать выполненные проверки, наблюдаемый итог и оставшиеся ограничения.

## Финальный результат

Первое автоматическое производство с реальными машинами и понятным циклом.

Коммит содержит ID T03, изменения и короткую запись проверки. Следующий тикет начинает работу с этого наблюдаемого результата.
