# T09 — Цели, Береговой маяк и объяснение экономики

Статус: запланирован. Веха: M1.

## Основная идея

Игрок понимает ближайшую цель и причину замедления.

## Цель

Три района приводят к постройке Берегового маяка с ясными условиями.

## Входные условия

Завершены: [T08](T08-research.md).

Прочитать [IDEA](../IDEA.md), [SCOPE](../SCOPE.md), [архитектуру](../ARCHITECTURE.md), [состояние](../STATE-AND-SAVE.md), [экономику](../ECONOMY.md) и [проверки](../VERIFICATION.md). При противоречии сначала актуализировать общий договор в [DECISIONS](../DECISIONS.md).

## Входит в тикет

- Каталог порогов, открытие без списания lifetime-выпуска и отдельные цены построек.
- Береговой маяк, панель следующей цели, причины простоя и предпросмотр улучшений M1.

## За границами тикета

Сам сброс, сюжетные находки и оставшиеся мегапроекты.

## Необходимые детали реализации

- Разделить discovered/unlocked/built/active. Расход запаса не откатывает порог открытия.
- Для маяка определить рецепт из доступных M1-материалов и питание; стоимость не списывается повторно.
- Показать конкретное ограничение: рабочий, питание, вход, ручное отключение. Скорость производства учитывает фазы, а не обещает постоянный поток.

## Критерии приёмки

- [ ] Траты на машины не уменьшают прогресс открытия.
- [ ] Маяк построен обычной экономикой; после постройки видно назначение будущего престижа.
- [ ] Каждый тип остановки M1 имеет понятное объяснение и действие восстановления.

## Проверка

Порог при низком текущем запасе, двойная покупка маяка, проверка всех причин простоя; вручную цель от старта до маяка.

Игровые тесты писать только через согласованные интерфейсы. В записи результата указать выполненные проверки, наблюдаемый итог и оставшиеся ограничения.

## Финальный результат

Завершённая первая цель и единый понятный интерфейс экономики M1.

Коммит содержит ID T09, изменения и короткую запись проверки. Следующий тикет начинает работу с этого наблюдаемого результата.
