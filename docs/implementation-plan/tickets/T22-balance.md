# T22 — Темп полной кампании

Статус: запланирован. Веха: M2.

## Основная идея

Количество систем превращается в последовательность полезных решений.

## Цель

Полная кампания проходит без тупиков и бессодержательных участков повторения.

## Входные условия

Завершены: [T21](T21-audio-accessibility.md).

Прочитать [IDEA](../IDEA.md), [SCOPE](../SCOPE.md), [архитектуру](../ARCHITECTURE.md), [состояние](../STATE-AND-SAVE.md), [экономику](../ECONOMY.md) и [проверки](../VERIFICATION.md). При противоречии сначала актуализировать общий договор в [DECISIONS](../DECISIONS.md).

## Входит в тикет

- Цены/выпуск/пороги M2, полезность исследований/перков, финальные рецепты.
- Реальные журналы прохождения и согласованный диапазон темпа.

## За границами тикета

Новые районы, исправление дизайна добавлением лишних валют, обещание длительности без прохождения.

## Необходимые детали реализации

- Сравнить разные приоритеты луча, два стартовых маршрута и минимум два метанабора.
- Выделить периоды ожидания без полезного доступного действия; менять причину, не только уменьшать все цены.
- Проверить что ранние районы остаются значимы, каждое открытие меняет решения, повторное освоение короче первого.

## Критерии приёмки

- [ ] Пройден путь до Сердца света без отладочной выдачи ресурсов.
- [ ] Есть измеренные длительности этапов и эффект сбросов; диапазон кампании отражает наблюдения.
- [ ] Нет обязательной единственной комбинации перков или пропускаемой находки, блокирующей сюжет.

## Проверка

Полный набор правил после численных изменений и ручные прохождения на ×1 с журналами. Пользовательский отзыв отделяется от технической проходимости.

Игровые тесты писать только через согласованные интерфейсы. В записи результата указать выполненные проверки, наблюдаемый итог и оставшиеся ограничения.

## Финальный результат

Каталог сбалансированных параметров и протокол полной кампании.

Коммит содержит ID T22, изменения и короткую запись проверки. Следующий тикет начинает работу с этого наблюдаемого результата.
