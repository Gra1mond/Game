# T04 — Карта, релейные маяки и питание

Статус: реализован и проверен; [PR #2 в dev](https://github.com/Gra1mond/Game/pull/2) открыт, ожидает подтверждения пользователя. Веха: M1.

## Основная идея

Расширение меняет доступное пространство и требует понятного энергобюджета.

## Цель

Можно выбрать остров, построить маяк и увидеть действующую цепочку связи.

## Входные условия

Завершены: [T03](T03-port.md).

Прочитать [IDEA](../IDEA.md), [SCOPE](../SCOPE.md), [архитектуру](../ARCHITECTURE.md), [состояние](../STATE-AND-SAVE.md), [экономику](../ECONOMY.md) и [проверки](../VERIFICATION.md). При противоречии сначала актуализировать общий договор в [DECISIONS](../DECISIONS.md).

## Входит в тикет

- Ручная карта первых районов, выбор/масштабирование, состояния видимости и доступности.
- Релейная связь, дальность, запрос мощности, приоритеты и остановка при недопитании.

## За границами тикета

Управляемый главный луч, постоянные случайные отключения и процедурная карта.

## Необходимые детали реализации

- Обнаруженная точка и достижимая точка различаются. Работает только цепочка активных реле.
- Питание распределяется по приоритету игрока и стабильному ID при равенстве. Выключенная ветка не разрушает постройки.
- Мощность и дальность берутся из каталога. Картинка сети строится из результата правил.

## Критерии приёмки

- [x] Строительство вне связи не списывает материалы.
- [x] Отключение промежуточного маяка выключает зависимую ветку; восстановление возвращает её.
- [x] Порт продолжает считать производство при другом выбранном районе; карта объясняет дефицит.

## Проверка

Цепочка из трёх реле, край дальности, дефицит и смена приоритета через GameSession; вручную масштаб/выбор.

Игровые тесты писать только через согласованные интерфейсы. В записи результата указать выполненные проверки, наблюдаемый итог и оставшиеся ограничения.

## Финальный результат

Рабочая карта с расширением и предсказуемым распределением питания.

Коммит содержит ID T04, изменения и короткую запись проверки. Следующий тикет начинает работу с этого наблюдаемого результата.

## Выполненная сверка и проверка

- **Критерий1:** неоткрытый остров отклоняется с `not_discovered`, открытый без действующего соседа — с `disconnected`; весь профиль и запас остаются прежними. Дальность160 включительна. После восстановления родительского реле строительство снова возможно по исходной цене.
- **Критерий2:** действительная цепочка ship→port→quartz→coastal проходит через три реле. Отключение quartz убирает обе зависимые линии, но сохраняет постройки, открытия и фазовый прогресс. Повторное включение восстанавливает связь без оплаты. Карта рисует только `derived.links`. Остановка станции port не выключает отдельное реле.
- **Критерий3:** оконный сценарий выбрал oil на общей карте; скрытый порт прошёл погрузку и доставил4 сплава. Запрос relay:oil=2 при равных приоритетах останавливает порт по стабильному ID; карта показывает нехватку питания и потерю связи зависимых островов. Приоритет relay:port=20 восстанавливает порт и цепочку. Старый груз выдаётся один раз, а не пересчитывается заново.
