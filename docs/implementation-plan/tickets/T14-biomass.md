# T14 — Живые отмели

Статус: запланирован. Веха: M2.

## Основная идея

Рост колонии добавляет выбор между текущим доходом и будущим расширением.

## Цель

Светомассу можно выращивать, собирать и вкладывать в охлаждение ранних производств.

## Входные условия

Завершены: [T13](T13-demo-gate.md).

Прочитать [IDEA](../IDEA.md), [SCOPE](../SCOPE.md), [архитектуру](../ARCHITECTURE.md), [состояние](../STATE-AND-SAVE.md), [экономику](../ECONOMY.md) и [проверки](../VERIFICATION.md). При противоречии сначала актуализировать общий договор в [DECISIONS](../DECISIONS.md).

## Входит в тикет

- Рост/урожай/доля реинвестирования, новое назначение рабочего и панель колонии.
- Оптика влияет на рост, светомасса улучшает бур/насос; расширение save schema.

## За границами тикета

Экосистемная симуляция, новые случайные виды организмов и ручной сбор каждой партии.

## Необходимые детали реализации

- Доля урожая в диапазоне 0..1; реинвестированная часть не поступает в кошелёк одновременно.
- Определить устойчивый старт колонии из доступных ресурсов и источник восстановления при нулевой площади.
- Добавить режим луча, причины простоя, данные сохранения и безопасные defaults для M1-профиля.

## Критерии приёмки

- [ ] Режим расширения снижает текущий сбор и увеличивает будущую отдачу.
- [ ] Кварц → колония → охлаждение буров создаёт наблюдаемую обратную связь.
- [ ] Колония автоматизирована, загрузка в середине роста не удваивает урожай.

## Проверка

Доли 0/1/промежуточная, отсутствие питания и загрузка; ручное сравнение дохода до/после обратной связи.

Игровые тесты писать только через согласованные интерфейсы. В записи результата указать выполненные проверки, наблюдаемый итог и оставшиеся ограничения.

## Финальный результат

Четвёртый способ добычи и новый экономический контур.

Коммит содержит ID T14, изменения и короткую запись проверки. Следующий тикет начинает работу с этого наблюдаемого результата.
