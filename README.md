## Установка и запуск

Скачайте официальный **Godot 4.7.2 stable Standard**, не .NET: [релиз](https://github.com/godotengine/godot/releases/tag/4.7.2-stable). Распакуйте архив для своей ОС; добавьте каталог в PATH или задайте полный путь. Для экспорта нужны **export templates 4.7.2 stable**, установка через Editor → Manage Export Templates. Экспорт и архив Windows относятся к T24.

```powershell
$env:GODOT = "C:\Tools\Godot\Godot_v4.7.2-stable_win64.exe"
& $env:GODOT --editor --path game
& $env:GODOT --path game
py scripts/check.py
py scripts/check.py --case simulation
py scripts/check.py --case port
py scripts/check.py --case network
py scripts/check.py --case beam
py scripts/check.py --case oil
py scripts/check.py --case quartz
py scripts/check.py --case research
```

```sh
# Linux/WSL; здесь установлен официальный бинарник с проверенной SHA256
export GODOT="$HOME/.local/bin/Godot_v4.7.2-stable_linux.x86_64"
"$GODOT" --editor --path game
"$GODOT" --path game
python3 scripts/check.py
python3 scripts/check.py --case simulation
python3 scripts/check.py --case port
python3 scripts/check.py --case network
python3 scripts/check.py --case beam
python3 scripts/check.py --case oil
python3 scripts/check.py --case quartz
python3 scripts/check.py --case research
python3 scripts/check.py --parse-only
```

`GODOT` по умолчанию — `godot`. Python3 — инструмент проверки, не зависимость игры. Проверка импортирует проект, компилирует **все** `.gd`, затем запускает сценарии. Ошибки в логе дают ненулевой статус, неизвестный/пустой набор — ошибка. Сейчас43 сценария: beam3, network7, oil9, port8, quartz7, research6, simulation3. Сохранений до T10 нет.

## Управление

- Начните с порта или насосной станции за20 сплава; W1 можно свободно переназначать между ними.
- Сборщик действительно проходит путь туда, погрузку и доставку. В кошелёк попадает только доставленный груз; прогресс, трюм и средняя отдача видны на экране.
- «Вернуть» возвращает сборщика; выбор другой цели в пути применится после возвращения, не уничтожая погруженный груз.
- Дополнительных сборщиков и увеличенный трюм можно купить за сплав. Дальнее судно выгоднее после улучшения трюма; сравнение отдачи берётся из игровых правил.
- «Насос» открывает схему давления/откачки/охлаждения и вкладку «Масло». Назначьте W1 кнопкой «Насос» в его строке; загруженный сборщик сначала доставит груз.
- Ровный режим даёт4 масла за партию; форсаж —6 с нагревом. При60 тепла насос автоматически остывает без добычи, даже без питания/рабочего: базовые6с сокращаются исследованием устойчивости. Смена режима действует со следующей партии.
- Во вкладке «Масло» отдельно строится/включается генератор и выбирается район масляного форсажа: порт или построенные рифы. Видны средняя добыча, оплаченный расход, баланс и запас времени без новой добычи. Генератор получает топливо первым; при пустом баке аварийное питание остаётся.
- «Кварц» показывает условия открытия: порт, насос и выпуск по8 сплава/масла. Первый бур32 сплава включает реле12; у каждого бура один оператор. Выберите конкретный бур в строке работника и нажмите «На бур».
- Бур проходит заряд → раскол → охлаждение. Партия4 выдаётся только за завершённый раскол. Питание ускоряет заряд, но не остальные фазы; выключение сохраняет работу. Во вкладке «Питание» можно освободить бюджет, выключив станцию порта, не его транзитное реле.
- Линза выбранного бура за4 кварца сокращает следующий базовый заряд8→6с. Начатый заряд и охлаждение сохраняются. Сравнивайте прогнозы с учётом фактической мощности, луча и выбранной цели форсажа.
- «Наука» открывает единственный корабельный пост: назначьте работника кнопкой «Наука» в его строке. Данные доступны сразу, без города/внешнего питания:1 за5с завершённой работы. При отзыве незавершённая работа теряется; пауза её сохраняет.
- Вместимость, устойчивость насоса, навигационная оптика и автосбор имеют предельные уровни; меню показывает полную цену, нехватку и текущий/следующий эффект. Это исследования текущего цикла, не постоянное метадерево.
- Кварцевая оптика ускоряет портовую дорогу, не погрузку и не генератор. Вместе с лучом первый уровень даёт ближний рейс3.7с; трюм/уже загруженный груз сохраняются. Линза бура остаётся отдельным локальным оснащением.
- Изученный автосбор нужно включить отдельно во вкладке «Наука». Он повторяет бесплатный разбор обломков, делит интервал с ручным нажатием/удержанием и не покупает/переназначает ничего сам.
- Удерживайте «Разобрать обломок» для бесплатного ручного сбора с ограничением 0.5 с.
- Пауза — кнопка или пробел, включая фокус на другой кнопке; потеря фокуса тоже ставит симуляцию на паузу.
- «Карта» показывает релейную сеть; «Порт» приближает действительные циклы сборщиков. Скрытые производства продолжают работать.
- Выбор острова — щелчок, список или стрелки при фокусе карты. Колесо/+− меняет масштаб, перетаскивание/WASD сдвигает, Home/«Сброс» возвращает вид.
- Постройте реле на открытом острове в дальности активного соседа. Отключение промежуточного реле разрывает зависимую ветку, не уничтожая постройки.
- Луч: район → «Луч [Enter]»/Enter либо ПКМ по острову; вкладка «Луч» даёт прогноз и подтверждение. Погрузка порта×2, набор давления насоса×2, скорость заряда рифов+100%; дорога/груз/раскол/охлаждение неизменны. С масляным форсажем временная скорость×2.5, не×3. «Без усиления» снимает бонус. Луч не заменяет реле.
- Во вкладке «Питание» меняются запрос и приоритет каждого реле/станции, видны факт и причина остановки. После ввода нажмите «Применить». Неполный запрос не запускает производство; сначала нужна действующая цепь реле.
