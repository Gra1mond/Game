GameSession кэширует NetworkRules после новых/изменённых сетевых состояний и смены оплаченной генерации, не пересчитывает неизменную сеть каждый tick. Snapshot возвращает отдельные copies derived.regions/consumers/links/range/power_limits/power_capacity/power_used/prices.relays. Питание разрешает производство; отключение не сбрасывает фазы/груз, пассивное охлаждение насоса продолжает работать. Обнаружение острова сохраняется при разрыве. UI выбор/масштаб/сдвиг не входят в профиль.

T06-команды: build{kind:oil|generator}, assign{worker,station:oil,target?:near|far}, mode{station:oil,mode:steady|overdrive}, generator{enabled:bool}, oil_boost{target:port|quartz,enabled:bool}; пустая цель допустима для отключения, кварц добавлен T07. Насос single-slot с queued_assignment, target всегда валиден. Mode — следующий выбор, cycle_mode — начатая партия. PortRules.advance/describe/loading_speed получают только фактически оплаченный портовый бонус. Масляные добыча/баланс — средние с охлаждением; oil_seconds игнорирует новую добычу.

T07-команды: build{kind:quartz}, assign{worker,station:quartz_N}, upgrade{id:quartz_lens,station:quartz_N}; power/beam/recall те же. Worker.phase=operating для насоса/буров. QuartzRules хранит charge/fracture/cooling и базовую работу; lens_level=0/1, cycle_lens_level=-1/0/1 фиксирует начатый заряд. Все три фазы требуют рабочего и питания. На шаге резерв генератора → сеть → резерв районного форсажа → Oil → Quartz → Port; такт возврата не считается работой новой станции. Форсаж рифов оплачивает весь активный цикл, включая охлаждение, за0.5/с; смена цели ждёт нового оплаченного шага.

Derived.quartz содержит отдельный производственный unlocked, требования/прогресс, station_ids/next_id/rate. Derived.stations[quartz_N] — фаза, работа, питание, оператор/очередь, установленная/зафиксированная линза, текущий/следующий заряд. Beam.quartz_drills и oil_boost.quartz_drills дают прогнозы следующих зарядов; без питания прогноз явно теоретический, не ниже минимальной1, фактический выпуск0. Не заменять релейный regions.unlocked производственным порогом. Полные поля/числа — STATE-AND-SAVE/ECONOMY.

- T12A после T12/до T13: локальные source/параметры/seed/lock → GLB/baked PBR/PNG для корабля, сборщика, порта и реальной upgraded-версии сборщика. Сначала качество/импорт/карточка/замеры в Godot, потом массовый арт. Люди только M2. Игроку Blender не нужен.
- [CREW-AND-TALENTS](docs/implementation-plan/CREW-AND-TALENTS.md): T17A — экипаж и три места капитана/инженера/штурмана, гарантированные роли/первый матрос, кредиты найма и конкретные предложения, модели людей. T17B — личный XP/12 узлов на героя, ветеран/врождённый модификатор/редкий пассив, случайные контракты заранее выбранной роли с сохранённым результатом.
- T18: 36 общих узлов, обычные общие очки за новые цели и престижные за существующее эхо. Полные заработанные бюджеты сохраняются, вложения возвращаются один раз, раскладка заново. Доступность ярусов после престижей сохраняется, но уровни/проходы покупаются заново без отдельного необратимого ключа.
- Личные герои/экипаж/XP/очки и кредиты текущего цикла сбрасываются. **Нет престижных покупок в личных деревьях и возврата их очков.** Шансы качества повышают выбранные общие таланты, не сам cycle_index. Ни одна обязательная цель не требует редкого героя. Стартовые материалы/кредиты выдаются один раз после новой раскладки, никогда не производят эхо.
- T20 завершает покрытие всей графикой, но первые человеческие модели обязательны уже в T17A. Миграции вводятся с T17A/T17B/T18, T23 проверяет всю цепочку. Не обнулять старые лодки/груз при обновлении и не применять второй стартовый набор.
- [SKILLS-RESEARCH](docs/implementation-plan/SKILLS-RESEARCH.md): godot-ui/assets-pipeline/GDScript, Blender modeling/materials/UV/export, MPFB2/CC0 как кандидат для людей. Навык — не установленный инструмент/генератор. Blender leaves имеют sibling dependencies, MCP исполняет произвольный код; готовность/качество здесь не доказаны.
- Локальный процесс — исходный вариант. В этой задаче не установлены Blender/новые навыки/asset packs, не сгенерированы модели, не вызваны платные API. Установки/облако/загрузка исходников требуют отдельного разрешения; подробные источники и лицензионные ограничения в исследовании.
